Linearity and Time Invariance

A system is linear if scaling the input scales the output and the response to a sum of inputs is the sum of the responses. It is time-invariant if delaying the input only delays the output. For an LTI system, knowing the responses ŷ1(t) and ŷ2(t) to two basic inputs x̂1(t) (a triangle) and x̂2(t) (a pulse) is enough to predict the output for any scaled, shifted sum of them:

a1x̂1(t-τ1) + a2x̂2(t-τ2) → a1ŷ1(t-τ1) + a2ŷ2(t-τ2)

Try it: each output plot shows the actual output (solid) and the LTI prediction (dashed). With the RC filter they always agree. With the squarer, change a1: the output grows like a12, and where the inputs overlap the output of the sum is not the sum of the outputs, so the squarer is not linear. Shifting still works, though (keep a1 = 1). With y(t) = t x(t), scaling and adding work but shifting does not: that system is linear but time-varying.
