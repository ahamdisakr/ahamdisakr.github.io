Interactive Fourier Transform Demo

Interactive Fourier Transform Demo

Slider changes the frequency f0 of the input cosine. It passes through a first-order low-pass filter, so the output is the input scaled by |H(f0)| and phase-shifted by φ(f0).

Input x Filter h/H Output y

x(t) = cos(2π f0 t)

t (s)

|X(f)| = 1⁄2 [δ(f-f0) + δ(f+f0)]

f (Hz)

h(t) = α e-α t u(t), α = 2π·50

t (s)

|H(f)| = α / √(α² + (2πf)²)

f (Hz)

y(t) = |H(f0)| cos(2π f0 t + φ(f0))

t (s)

|Y(f)| = 1⁄2 |H(f0)|[δ(f-f0) + δ(f+f0)]
