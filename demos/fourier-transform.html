Frequency Response: A Sinusoid Through a Filter

A cosine of frequency f0 passes through a first-order low-pass filter with a 50 Hz cutoff. Because the filter is LTI, the output is a cosine at the same frequency, scaled by the magnitude response |H(f0)| and shifted by the phase response φ(f0). Use the slider to change f0.

Try it: start at a low frequency: the output looks just like the input. Move f0 to the 50 Hz cutoff: the output drops to 1/√2 ≈ 0.71 of the input and lags it by 45°. At 400 Hz it is only about 0.12 of the input. Through all of this the output keeps the frequency of the input: an LTI system can only scale and delay a sinusoid, never change its frequency. That is why the output spectrum is the input spectrum multiplied by |H(f)|. To measure the delay, zoom into the time plots (Ctrl + scroll or pinch, drag to pan, double-click to reset).

Predict, then check

At what input frequency is the output half as large as the input?

Where |H(f0)| = 1/√(1 + (f0/50)²) = 1/2, that is f0 = 50√3 ≈ 87 Hz. Check it with the slider and the readout under the output.

Can the output ever lag the input by more than 90°?

No. For this first-order filter φ(f0) = −arctan(f0/50), which approaches −90° but never reaches it (at 400 Hz it is −82.9°).
