System Properties

Five questions classify a system. Linear: does a weighted sum of inputs give the same weighted sum of outputs? Time-invariant: does delaying the input only delay the output? Causal: does the output depend only on present and past inputs? Memoryless: does the output at each instant depend only on the input at that instant? Stable (BIBO): does every bounded input give a bounded output? The same questions apply in continuous and in discrete time. Each test below tries one example. A single failing example proves that a property fails; a passing example only supports it, so the table gives the verdict from the definition.

Try it: choose the squarer and the linearity test: with a = 2 the output of the combined input (solid) is far from the combination of the outputs (dashed). Set a = 1 and b = 0: now they agree, which is why one passing example proves nothing. Choose y(t) = t x(t) and the time-invariance test, and move t0: the two outputs drift apart, because the gain depends on when the input arrives. With y(t) = x(t + 1) and the causality test, the inputs agree before t = 1 but the outputs do not: the system reacts before the change happens. Try the integrator with the stability test: a bounded step gives a ramp that never stops growing. Then switch to discrete time and choose the downsampler y[n] = x[2n] with the time-invariance test: delaying the input by one sample does not delay the output by one sample. Predict, then check

Is y(t) = 2x(t) + 1 linear? Its graph of y against x is a straight line.

No. A linear system must give zero output for zero input, and this one gives y = 1. In the linearity test the two outputs differ by exactly a + b − 1. (It is incrementally linear: the change in output is linear in the change in input.)

Is y(t) = x(2t) time-invariant? Causal?

Neither. Delaying the input by t0 gives x(2t − t0), but delaying the output gives x(2t − 2t0). And for t > 0, y(t) = x(2t) uses an input value from the future.

The upsampler sets y[n] = x[n/2] for even n (and 0 for odd n). For n > 0 it only uses past samples. Is it causal?

No. For negative n, n/2 is later than n: y[−4] = x[−2] uses a future sample. Causality has to hold for every n, negative ones included.

This test has no parameter.
